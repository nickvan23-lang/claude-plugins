# Wayloom for Claude Code

Run account-linked browser tasks, read rendered pages, and inspect metered usage and results.

```
/plugin install wayloom --marketplace nickvan23-lang/claude-plugins
```

The plugin connects to the hosted Wayloom MCP server at `https://wayloom.getseekx.com/mcp`. It works right away as a free guest trial with no signup. The hosted browser runs separately from your own browser and cannot reach your sign-ins or local files.
