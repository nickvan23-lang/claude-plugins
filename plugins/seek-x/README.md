# Seek X for Claude Code

Search, read, map, batch, crawl and extract web information with your Seek X account.

```
/plugin install seek-x --marketplace nickvan23-lang/claude-plugins
```

The plugin connects to the hosted Seek X MCP server at `https://getseekx.com/mcp`. It works right away as a free guest trial with no signup. To use your own account and saved results, run `/mcp`, pick `seek-x` and sign in; each verified account gets 100 free credits per UTC day.
