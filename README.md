# getseekx Claude Code plugins

```
/plugin marketplace add nickvan23-lang/claude-plugins
/plugin install seek-x@getseekx
/plugin install wayloom@getseekx
```

Both work immediately as free guest trials. Run `/mcp` to sign in to your own account.

| Plugin | What it does |
| --- | --- |
| [seek-x](plugins/seek-x) | Web search, page reading, site mapping, bounded crawls, structured extraction |
| [wayloom](plugins/wayloom) | Hosted browser tasks with metered credits and traceable results |
